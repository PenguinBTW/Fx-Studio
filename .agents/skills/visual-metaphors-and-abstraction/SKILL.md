# Visual Metaphors & Conceptual Abstraction

Production standards, conceptual mapping frameworks, and mandatory pre-production planning rules for physicalizing abstract, invisible, or technical concepts (algorithms, economic forces, systems architecture, historical dynamics) into grounded 3D/2.5D spatial environments in Viopls video essays.

## When to Use

- Planning what visual objects, physical environments, or spatial models represent a script paragraph.
- Translating intangible ideas (e.g., latency, inflation, cryptographic hashing, attention mechanisms) into tangible mechanical or environmental systems.
- Eliminating generic clip-art clichés (e.g., floating lightbulbs, generic gears, floating spreadsheets).
- Enforcing the mandatory pre-production planning deliverable: **`visual_plan.md`**.

---

## 1. The Pre-Production Planning Gate [RULE]

**Autonomous agents and directors are strictly forbidden from writing scene code (`defineScene`) or storyboarding shots before producing a Visual Architecture Plan (`visual_plan.md`).**

An agent must not jump straight into code. Planning forces the model to deliberate on physical mechanics, scale, focal hierarchy, and material grounding.

Before writing code, execute this 4-step conceptual deconstruction:

## 2. Core Metaphor Principles

### 2.1 The "One Core Metaphor Per Chapter" Rule [RULE]
- Never mix competing physical domains within a single narrative chapter.
- **Forbidden:** Starting a chapter explaining memory cache as a "library bookshelf," cutting to a "highway traffic jam," and then cutting to a "water pipeline."
- **Mandatory:** Commit to a single cohesive physical system (e.g., an automated industrial sorting warehouse) and map all subsystem interactions within that environment.

### 2.2 Physicalizing Invisible Forces [GUIDANCE]
Map non-physical concepts to concrete physical properties:

| Invisible / Abstract Force | Physical Property | Visual Realization in 3D/2.5D |
|---|---|---|
| **Latency / Delay** | Fluid Friction / Viscosity | Objects moving through high-viscosity oil, decelerating with visible fluid drag. |
| **Compute / Processing** | Heat & Luminescence | Silicon surfaces heating to amber incandescence; cooling fins venting heat haze. |
| **Data Integrity / Proof** | Mechanical Interlocking | Heavy milled steel teeth or mortise joints snapping together with zero tolerance. |
| **Inflation / Dilution** | Material Erosion / Porosity | Solid marble monuments fracturing, becoming porous, crumbling into sand. |
| **Risk / Volatility** | Structural Tension | Suspended steel cables vibrating, fraying under excessive tension, oscillating violently. |

### 2.3 The Cliché Elimination Blacklist [RULE]
Never generate the following generic tropes unless explicitly requested:
- **No Floating Lightbulbs:** Replace with physical power-grid substations arcing or filament ignition inside vacuum tubes.
- **No Disconnected Floating Gears:** Replace with fully interlocked, oil-lubricated mechanical drivetrains with visible drive shafts.
- **No Floating 2D Spreadsheets:** Replace with 3D tactile ledgers, punch-card sorting machines, or spatial volumetric data cubes.
- **No Generic Network Nodes with Connecting Lines:** Replace with physical subterranean fiber conduits, copper railway relays, or illuminated vacuum manifolds.

## 3. Spatial Composition & Focal Hierarchy

### 3.1 The 0.3-Second Readability Test [RULE]
Viewers must identify the subject of interest in less than 300 milliseconds.
- **The Value Hierarchy:** The hero metaphor element must have the highest luminance contrast and sharpest depth-of-field focus.
- **Negative Space Rule:** Maintain 60%–70% clean negative space around the hero metaphor. Do not clutter the frame with secondary technical widgets that obscure the central idea.
- **Diegetic Anchoring:** Per `video-design`, any descriptive typography must physically mount to or project from the metaphor geometry (e.g., laser-etched serial numbers, projected gauge marks).

---

## 4. Pre-Production Planning Checklist

Before submitting scene scripts or starting 3D implementation:

- [ ] **Plan Documented:** Is `visual_plan.md` created with a complete Conceptual Mapping Table?
- [ ] **Unified Domain:** Does the chapter adhere to a single physical system without metaphor mixing?
- [ ] **Zero Clichés:** Are floating lightbulbs, disconnected gears, and floating spreadsheets eliminated?
- [ ] **Tangible Materials:** Are materials specified with real-world finishes (brushed metals, glass, liquids, brutalist stone)?
- [ ] **Focal Clarity:** Does the hero object command visual dominance with at least 60% negative space around it?
