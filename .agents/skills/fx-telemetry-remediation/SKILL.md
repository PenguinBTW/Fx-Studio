# f(x) Studio: Telemetry Remediation & Directorial Self-Correction

Operational remediation protocols, automated rule resolution workflows, and code repair recipes for addressing kinematic telemetry flags (`F01–F16`) emitted by **f(x) Studio**'s Kinematic Telemetry Engine (rules in [`scripts/motion/flags.ts`](file:///c:/Users/brosf/Documents/A%20vio%20projects/VioPls/Agentic%20motion%20design%20toolset/app/scripts/motion/flags.ts)).

## When to Use

- Resolving CI build failures or blocking Tier A flags (`F04`, `F05`, `F10`, `F13`, `F16`).
- Interpreting telemetry reports generated by `bun scripts/render.ts motion`.
- Applying machine-actionable repair directives from `AgentHeal` ([`heal.ts`](file:///c:/Users/brosf/Documents/A%20vio%20projects/VioPls/Agentic%20motion%20design%20toolset/app/src/engine/heal.ts)).
- Documenting justified artistic exceptions (creative waivers) in `findings.json`.
- Eliminating sub-pixel edge shimmer (`F15`), bloom bloat (`F11`), and color gamut drift (`F12`).

## 3. Tier A Objective Remediation Recipes (Blocking in CI) [RULE]

Tier A flags represent physical geometry overlap, clipping, or fatal render faults. **They cannot be waived; they must be resolved in code.**

### 3.1 Rule `F04`: Text Layout Collision (Area Overlap > 2%)
* **Root Cause:** Two text blocks overlap on screen, or 2D overlay text intersects a foreground 3D object, or incoming/outgoing text collide during a scene transition.
* **Remediation Recipe 1 (3D Model Avoidance via `getScreenBounds`):**
  ```typescript
  // Dynamically position text above or below the 3D hero model bounds:
  const [minX, minY, maxX, maxY] = heroModel.getScreenBounds(ctx.threeCam, ctx.W, ctx.H);
  
  // Anchor text cleanly 40px above the highest model vertex:
  const textY = Math.max(90, minY - 40);
  ctx.renderText('SYSTEM ACTIVE', ctx.layer2d.ctx, f.t, 960, textY);
  ```
* **Remediation Recipe 2 (Transition Seam Collision via `overlayDuck`):**
  ```typescript
  // In defineScene render loop: Multiply text opacity by transition ducking curve
  const duckAlpha = ctx.overlayDuck(f.tin, f.tout);
  ctx.layer2d.ctx.globalAlpha = duckAlpha;
  // Outgoing text hits 0% by tout=0.35; Incoming text delays until tin=0.55
  ```

### 3.2 Rule `F05`: Viewport Safe Boundary Clipping (Area Outside Safe Box > 5%)
* **Root Cause:** Visual elements or kinetic typography extend beyond the 90% safe margin (16:9) or Central 60% Core (9:16 Shorts).
* **Remediation Recipe 1 (Responsive `LayoutNode` Pinning):**
  ```typescript
  import { LayoutNode } from '../../engine/transform';
  
  // Pin text to safe title anchor rather than raw screen coordinates:
  const titleNode = new LayoutNode({
    anchor: 'top-center',
    offset: [0, 80], // 80px down from top edge (well inside safe box)
    safeZone: 'action',
  });
  ```
* **Remediation Recipe 2 (Camera Frustum Pullback):**
  ```typescript
  // Pull camera back along Z to expand visible field:
  ctx.rig.position = [0, 1.2, 7.5]; // Increased from 5.0
  ctx.rig.setLensMm(35);            // Widen lens from 50mm
  ```

### 3.3 Rule `F10`: Cut Inside Spoken Vocal Word
* **Root Cause:** A scene cut in `project.json` lands directly in the middle of an active vocal word duration.
* **Remediation Recipe:**
  1. Inspect `app/public/data/lyrics.json` or `narration_guide.md` for word boundaries.
  2. Shift the transition `at` timestamp in `project.json` forward or backward to the nearest natural vocal pause ($\ge 120\text{ ms}$ silence):
  ```json
  // BEFORE (Collision at 6.25s during word "intentional"):
  { "from": "scene_a", "to": "scene_b", "at": 6.25, "duration": 0.5 }
  
  // FIXED (Shifted to word pause at 6.60s):
  { "from": "scene_a", "to": "scene_b", "at": 6.60, "duration": 0.5 }
  ```

### 3.4 Rule `F13`: Frame Render Time Budget Overrun (> 25 ms/frame in Preview)
* **Root Cause:** Uploading massive Canvas2D surfaces per frame or re-allocating WebGL buffers inside `render()`.
* **Remediation Recipe:**
  1. **Replace Canvas2D Cards with `SDFBatch`:** Replace per-frame `ctx2d.fillRect()` with instanced fragment SDFs in [`sdf.ts`](file:///c:/Users/brosf/Documents/A%20vio%20projects/VioPls/Agentic%20motion%20design%20toolset/app/src/engine/sdf.ts).
  2. **Eliminate Render-Time Allocations:** Move all `new THREE.Mesh()`, `new THREE.BufferGeometry()`, and material constructions out of `render()` into `setup()` or `init()`.

### 3.5 Rule `F16`: Unintended Screen Blackout / Whiteout (Blank Run > 0.3s)
* **Root Cause:** A transition quad fails to render texture inputs, or `gl.clear()` occurs without drawing subsequent geometry, leaving the viewport completely empty.
* **Remediation Recipe:**
  Verify that the transition class binds valid textures in `render()` and explicitly flushes geometry:
  ```typescript
  gl.setRenderTarget(out);
  gl.clear(true, true, true);
  this.material.uniforms.texA.value = texA;
  this.material.uniforms.texB.value = texB;
  gl.render(this.scene, this.camera);
  gl.resetState(); // Restore state cache
  ```

## 4. Tier B Calibrated Benchmark Remediation & Waivers

Tier B flags indicate empirical deviations from baseline productions. They can either be tuned or formally waived.

| Rule | Description | Remediation Recipe | Valid Artistic Waiver Example |
|---|---|---|---|
| **`F09`** | Kick Drum Kinetic Response | Increase transient impulse scalar: `ctx.rig.shake += f.a.kick * 0.15;` | *"Deliberate ambient interlude; drum transients subdued."* |
| **`F11`** | Highlight Bloom Bloat | Raise bloom threshold in post: `return { bloom: 0.10 };` | *"Intentional supernova laser burst at Act 2 climax."* |
| **`F12`** | Off-Palette Gamut Wash | Clamp custom shader RGB output to project tokens (`--bone`, `--ash`). | *"Monochromatic infrared night-vision sensor styling."* |
| **`F14`** | Adaptive Sampler Stress | Reduce geometry micro-features or simplify high-density line segments. | *"Complex mechanical explosion with 10k flying shards."* |
| **`F15`** | Edge Shimmer / Chatter | Increase minimum line width to $1.5\text{px}$; apply `fwidth()` shader smoothing. | *"Deliberate CRT television scanline flicker effect."* |

## 5. The Waiver Logging Protocol (`findings.json`) [RULE]

When a Tier B flag is caused by an **intentional creative choice**, log an explicit waiver in `app/src/scenes/<project>/findings.json`:

```json
{
  "project": "child_lock",
  "audit_timestamp": "2026-10-24T12:00:00Z",
  "waivers": {
    "F11-0520-0580-001": "Intentional electrical spark flare on severed cable cut point",
    "F12-2000-2400-001": "Monochromatic schematic diagram styling in Beat 2",
    "F08-2700-3000-001": "Dramatic silent hold on Interlock glyph before scale reveal"
  }
}
```

- **Waiver ID Format:** Must match the content-addressed flag ID emitted by the telemetry engine:
  $$\text{ID} = \text{Rule} - \text{round}(t_0 \times 100) - \text{round}(t_1 \times 100) - \text{index}$$
- **Prohibited:** Never log blanket wildcards (`"F11-*": "looks fine"`). Every waiver must cite an exact timestamp window with a one-line artistic justification.
