## 1. Overview & Audit Scope

The `v0.6.1` release is an engine-wide stability, numerical correctness, and hardware state hardening patch following an exhaustive multi-subagent audit of the core engine and standalone transition systems. Cross-referencing against the engine's 6 foundational architectural invariants ([`engine-overview.md`](../architecture/engine-overview.md)), this patch resolves 24 distinct critical bugs across core loops, WebGL shaders, camera rig math, physical solvers, asset pipelines, kinetic typography, and multi-format video exports.

All modifications strictly preserve backward compatibility, ensure zero memory/GPU leaks, maintain $C^1$ velocity and temporal continuity, and pass all 16 milestone and subsystem test suites with zero failures.

## 2. Architectural Invariants Enforced

| Invariant | Description | Enforced In v0.6.1 |
| :--- | :--- | :--- |
| **Invariant 1: Mathematical Determinism** | $\text{Frame} = f(t)$ across sub-frame sampling (1 to 324 spp). Zero state mutation during probe queries. | Removed `rec.lastT = t` from `sampleScene()`; restored true $C^1$ velocity continuity to `springStep`. |
| **Invariant 2: WebGL State Cache** | `renderer.resetState()` called at the end of every non-Three pass to eliminate state poisoning. | Enforced in `Post.render()`, `Compositor.draw()`, and all 9 standalone transitions. |

| **Invariant 5: Font Readiness Gate** | Guaranteed font metrics before initial layout computation. | Guarded fallback fonts in `strokeText` and preserved explicit newlines across kinetic layout. |
| **Invariant 6: Logical Coordinate Space** | Analytical geometry operates in logical 1920×1080 space; `PX_SCALE` reserved for sub-pixel anti-aliasing. | Fixed orthographic projection depth clipping in `ViewportSpace.worldToScreen()`. |

## 3. Detailed Audit Findings & Applied Fixes

### Domain 1: Core Loop, Drivers, Lifecycle & Export Pipeline

1. **WebGL Framebuffer Feedback Loop in Multi-Scene Overlaps ([`engine.ts`](../../app/src/engine/engine.ts))**:
   - *Issue*: When three or more scenes overlapped concurrently, crossfading sampled from `under` (holding `this.mixRT.texture`) while simultaneously rendering into `this.mixRT`. This triggered an illegal WebGL framebuffer texture feedback loop.
   - *Fix*: Introduced a 2-target ping-pong ring `this.mixRTs = [makeRT(W, H, { depthBuffer: false }), makeRT(W, H, { depthBuffer: false })]` with alternating modulo indexing (`mixIdx % 2`).

2. **Sequential Delta-T Corruption in `sampleScene` ([`engine.ts`](../../app/src/engine/engine.ts))**:
   - *Issue*: Auxiliary transition sampling mutated `rec.lastT = t`. When the scene subsequently rendered its normal timeline frame, the jump was falsely flagged as `seeked`, zeroing delta-time and corrupting stateful transitions.
   - *Fix*: Removed `rec.lastT = t` mutation from `sampleScene`, ensuring pure auxiliary queries do not corrupt primary playback state.

3. **DSL 3D Text Multi-Material Opacity Poisoning ([`dsl.ts`](../../app/src/engine/dsl.ts))**:
   - *Issue*: `SceneContext.text3D()` cast `(c as THREE.Mesh).material` directly to a single `THREE.Material`. Because `ExtrudedText` produces multi-material arrays `[faceMat, sideMat]`, `m.opacity = opts.opacity` assigned a property to the array object itself; face and side materials remained fully opaque.
   - *Fix*: Handled both `THREE.Material` and `THREE.Material[]`, properly propagating opacity and transparency flags to every element.

4. **Export Validation Rejection of Adaptive Sampling ([`export.ts`](../../app/src/engine/export.ts))**:
   - *Issue*: `ExportPipeline.validate()` evaluated `Number.isFinite(opts.samples)`, rejecting `'auto'` and `AdaptiveSampling` objects (`{ min, max, tol }`), aborting CLI exports.
   - *Fix*: Added explicit validation support for `'auto'` and object-based adaptive sampling specifications.

5. **FFmpeg Album Art Hijacking & Pipe Error Handling ([`export.ts`](../../app/src/engine/export.ts), [`render.ts`](../../app/scripts/render.ts))**:
   - *Issue*: `buildFFmpegArgs()` lacked explicit stream mapping (`-map 0:v:0`). If audio tracks contained embedded ID3 album artwork, FFmpeg selected the cover art as the primary video stream. Furthermore, `render.ts` lacked error boundaries around stdin pipe writes and did not check `ff.exitCode`.
   - *Fix*: Added `-map 0:v:0` and `-map 1:a:0?` arguments, wrapped pipe writes in try-catch handlers, and asserted `ff.exitCode === 0`.

6. **Driver Zero-Division & Optional Chaining Safeguards ([`driver.ts`](../../app/src/engine/driver.ts))**:
   - *Issue*: `ClockDriver` divided by zero on `bpm <= 0` or `duration <= 0`; `AudioDriver` called `this.audioData.sample(clampedT).rms` without optional chaining, crashing when sample returned null; `SpeechDriver` spread `cues` without verifying array type.
   - *Fix*: Added floor bounds, null guards, and safe defaults.

7. **Preview Bridge Initialization ([`main.ts`](../../app/src/main.ts))**:
   - *Issue*: `window.__motion` and `window.__pdoom` were only instantiated in export mode (`?export=1`), leaving preview player sessions with an undefined bridge.
   - *Fix*: Initialized a fully populated `previewBridge` contract in `setupPlayer()`.

### Domain 2: Math, Camera Rig, Layout & Physical Solvers

1. **Velocity Discontinuity ($C^1$) in `springStep` ([`util.ts`](../../app/src/engine/util.ts))**:
   - *Issue*: The under-damped branch used $1 - e^{-\zeta \omega_n t} \cos(\omega_d t)$, missing the $\frac{\zeta}{\sqrt{1-\zeta^2}} \sin(\omega_d t)$ velocity term, producing non-zero onset velocity and jerky animation snaps.
   - *Fix*: Restored the complete second-order ODE solution, achieving true $C^1$ velocity continuity at $t=0$.

2. **Degenerate Camera Basis Normalization ([`camera3d.ts`](../../app/src/engine/camera3d.ts))**:
   - *Issue*: When camera position equaled target, vector subtraction produced zero-length forward vectors, resulting in `NaN` rotation matrices.
   - *Fix*: Guarded `rawLen < 1e-6` with fallback holding `+Z` forward.

3. **Orthographic Viewport Depth Culling ([`viewport.ts`](../../app/src/engine/viewport.ts))**:
   - *Issue*: `worldToScreen()` applied `ca.w <= 0.0` clipping indiscriminately. Under orthographic projection, $w=1$, but coordinates were subject to incorrect bounds checks.
   - *Fix*: Enforced perspective-only depth clipping (`cam instanceof THREE.PerspectiveCamera`).

4. **Camera Rig Unsorted Waypoint Trajectory ([`rig.ts`](../../app/src/engine/rig.ts))**:
   - *Issue*: `setPath()` assumed caller waypoints were pre-sorted by time. Unsorted arrays produced inverted bisection bounds and broken spline evaluations.
   - *Fix*: Enforced automatic sorting `[...waypoints].sort((a, b) => a.t - b.t)` and handled single-waypoint static framing.

### Domain 3: WebGL Hardware, Shaders, Compositor & Post

1. **GLSL Compilation Crash in `MATTE_FRAG` ([`graph.ts`](../../app/src/engine/graph.ts))**:
   - *Issue*: `MATTE_FRAG` explicitly defined `float luma(vec3 c)`. Because `FSPass` prepends `GLSL_COMMON` (which already declares `luma`), WebGL2 shader compilation crashed with duplicate function definition errors.
   - *Fix*: Removed duplicate `luma` declaration from `MATTE_FRAG`.

2. **State Cache Leak Violations ([`post.ts`](../../app/src/engine/post.ts), [`gl.ts`](../../app/src/engine/gl.ts), [`transitions/*`](../../app/src/transitions/))**:
   - *Issue*: `Post.render()`, `Compositor.draw()`, and 9 standalone transitions failed to invoke `renderer.resetState()`. This poisoned subsequent Three.js material bindings, depth masks, and blend states.
   - *Fix*: Added `renderer.resetState()` across all passes, compositor draw calls, and all transition blocks.

3. **Non-Linear Alpha Premultiplication Halos ([`post.ts`](../../app/src/engine/post.ts))**:
   - *Issue*: In `post.ts`, sRGB output was multiplied directly by alpha (`sat(s) * finalAlpha`). Because sRGB gamma compression is non-linear, multiplying encoded sRGB by alpha creates dark edge halos around transparent overlays in ProRes 4444 and WebM. Furthermore, volumetric scattering and DoF bokeh were omitted from `finalAlpha`.
   - *Fix*: Premultiplied in linear color space prior to `toSRGB(sat(col) * finalAlpha)` and incorporated volumetric scatter into the composite alpha calculation.

4. **Shader Numerical Singularities ([`glsl/common.ts`](../../app/src/engine/glsl/common.ts))**:
   - *Issue*: Negative values in `toLinear()` caused `pow()` on negative numbers resulting in `NaN`; `sdSegment` and `sdCapsule` divided by `dot(ba, ba)` without checking for degenerate points ($a=b$); `smin` divided by $k$ without guarding $k \le 0$; `fwidth(d)` in `aaFill` and `aaStroke` divided by zero on flat geometry.
   - *Fix*: Added `max(c + 0.055, 0.0)`, dot product epsilon guards, $k \le 1e-6$ minimum clamps, and `max(fwidth(d), 1e-5)` thresholds.

5. **Per-Frame GPU Texture Thrashing in `CompositorGraph` ([`graph.ts`](../../app/src/engine/graph.ts))**:
   - *Issue*: `CompositorGraph.clear()` previously disposed all `layerRTs` and cleared the map. When called inside a per-frame scene render, this created and destroyed WebGL render targets 60 times per second.
   - *Fix*: Decoupled layer clearing from target lifecycle (`clear()` resets `this.layers = []`; target disposal is reserved for `dispose()`). Also added save/restore logic for the renderer's clear color and alpha.

### Domain 4: Typography, 3D Assets, Colors & Transitions

1. **Destruction of Shared Master Assets in `GLTFInstance.dispose()` ([`gltf.ts`](../../app/src/engine/gltf.ts))**:
   - *Issue*: In `gltf.ts`, disposing an instance traversed and called `.dispose()` on child geometries, materials, and textures. Because Three.js instances share master geometries and textures cached in `GLTFManager.cache`, disposing one instance corrupted all other active or future instances of that model.
   - *Fix*: Removed master asset disposal from `GLTFInstance.dispose()`, restricting it to animation mixer uncoupling and scene graph clearance. Master asset disposal is properly isolated to `GLTFManager.clearCache()`.

2. **8-Digit Hex Channel Scrambling ([`tokens.ts`](../../app/src/engine/tokens.ts), [`palette.ts`](../../app/src/engine/palette.ts))**:
   - *Issue*: 8-digit hex `#RRGGBBAA` was parsed as a 24-bit integer: `(n >> 16) & 255` extracted green as red, blue as green, and alpha as blue.
   - *Fix*: Implemented proper 32-bit unsigned bitwise extraction: `r = (n >>> 24) & 255`, `g = (n >>> 16) & 255`, `b = (n >>> 8) & 255`, and `a = (n & 255) / 255`.

3. **Knockout Halo Alpha Decoupling ([`text.ts`](../../app/src/engine/text.ts))**:
   - *Issue*: In `KineticText.render()`, standard multi-line text halo drawing did not multiply `ctx.globalAlpha *= this.style.alpha`. When fading out text blocks, the knockout halo under-stroke remained at 100% opacity.
   - *Fix*: Applied `ctx.globalAlpha = this.style.alpha` prior to stroke rendering.

4. **Mirror Shatter Center Singularity ([`mirror_shatter.ts`](../../app/src/transitions/mirror_shatter.ts))**:
   - *Issue*: `normalize(fromCenter)` evaluated to `normalize(vec2(0.0))` at the exact screen center, returning `NaN` and producing corrupted black tiles.
   - *Fix*: Guarded with `fcLen > 1e-4 ? fromCenter / fcLen : vec2(0.0, 1.0)`.

5. **Headless DOM Reference Errors ([`gl.ts`](../../app/src/engine/gl.ts))**:
   - *Issue*: `Layer2D` unconditionally invoked `document.createElement('canvas')`. In headless CLI test runners (such as `test_seam.ts`), this threw an uncaught `ReferenceError: document is not defined`.
   - *Fix*: Added headless mock canvas and safe context scaling fallbacks when `document` or `CanvasRenderingContext2D` is undefined.
