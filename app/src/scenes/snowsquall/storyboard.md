# snowsquall — storyboard

1. **t≈2s — CALM.** Row of snowy rooftops recedes left→right under a
   slate sky. Warm windows (two flicker). A cat silhouette walks the
   far roofline. Fine far-layer snow only.
2. **t≈6s — THE FRONT.** A textured white wall is on the left edge,
   advancing; the leftmost house is already dissolving. Snow layers
   thicken, gust stripes rake the rooftop snow into streaks.
3. **t≈11s — WHITEOUT.** Frame is milk. Only the biggest near flakes
   read as grey streaks; the lamp pool is a dim coin of light.
4. **t≈14s — THE GAP.** The wall thins to gauze; rooftops ghost back
   right→left. A hooded figure crosses the lamplit gap between houses;
   chimney smoke streams sideways.
5. **t≈18s — SETTLED.** The row re-reads through steady snowfall —
   windows warm again, a smoke column rises off the church window.
