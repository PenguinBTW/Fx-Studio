# hummingbird — storyboard

| fig | t | beat |
|-----|---|------|
| 01 | 0–5 | FIRST LIGHT — still vine, shafts, dew glints, bee circling the cluster |
| 02 | 5–10 | DART · HOVER · SIP — bird enters, hover chain at blooms A→B, sip dips |
| 03 | 10–17 | CHAIN OF BLOOMS — bloom C jostled (dew drops), bloom D, dart to perch |
| 04 | 17–24 | PREEN · DEPART — perch flicks, exit dart, vine alone in stronger dawn |

Beats: still → enter → feed chain → jostle → perch → exit.
