# Visual Architecture Plan

**Chapter / Segment:** CHLADNI — Order From Vibration
**Core Abstract Concept:** Resonance imposing hidden order on chaos; a physical law made visible
**Primary Physical Domain:** Vibration laboratory — a driven steel plate rig on an optics bench

---

## 1. The Conceptual Mapping Table

| Script Abstract Concept | Real-World Physical Metaphor | Tangible Form & Materials | Dynamic Visual State Change |
|---|---|---|---|
| *Hidden mathematical law* | Square steel Chladni plate | Brushed steel plate, centre-clamped on a brass driver column, machined rig base | Plate stays visually still while its standing-wave pattern reorganizes matter |
| *Chaos / noise* | Loose salt grains | ~4500 instanced crystalline grains scattered uniformly on the plate | Grains jitter, lift, then migrate to nodal lines |
| *Resonant modes* | Stepped drive frequency | Machined drive module with etched mode readout + status LED | Display rolls to a new frequency; a pulse ring sweeps the plate rim; grains re-form a new figure |
| *Order made visible* | Chladni nodal figures | Bone-white grain ridges tracing zero-displacement curves | Figure snaps into legibility within ~1.8s, then holds with live tremor |

## 2. Anti-Cliché Audit (Forbidden Tropes & Replacements)
- **Forbidden Cliché:** Floating glowing network nodes / generic "data is beautiful" webs.
- **Grounding Replacement:** A real bench instrument — clamped plate, drive column, milled base — under one motivated overhead rig lamp.
- **Forbidden Cliché:** Decorative HUD jargon and fake scope grids.
- **Grounding Replacement:** A single diegetic mode readout etched on the drive module (mode indices + Hz), physical and mounted.

## 3. Spatial Hierarchy & Eye-Tracking Map
- **Primary Hero (60%):** The grain figure on the plate — highest luminance contrast (bone grains on dark steel), sharpest focus.
- **Secondary Support (30%):** Rig base + driver column + mode readout — mid-dark, context only.
- **Ambient Floor (10%):** Wireframe bench edges, volumetric haze, depth falloff into `--void`.

## 4. Palette (strict)
`--void` background, `--bone` grains/edges/label, `--ash` rig secondary lines and dim readout, `--signal` ONLY for the rim pulse at each mode step (the thesis-reveal moment: order appearing).
